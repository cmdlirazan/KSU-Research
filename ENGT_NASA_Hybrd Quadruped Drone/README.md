# Robotic Drone Navigation in Complex Terrains for NASA's Space Exploration
Hybrid ground-aerial robot with soft robotic 3D-printed quadruped legs for mobility on Martian topography.

## Features:
- Biomimetic quadruped locomotion for navigating diverse Martian topography
- Powered by Arduino Uno Rev 3

## Installation:
```bash
git clone https://github.com/cmdlirazan/Robotic-Drone-Navigation-in-Complex-Terrain-s-For-NASA-s-Space-Exploration.git
```
Upload the code to the Arduino Uno Rev 3.
